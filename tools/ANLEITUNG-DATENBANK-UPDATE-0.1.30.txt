DATENBANK-UPDATE FÜR VERSION 0.1.30
===================================

1. Die Webanwendung zunächst noch nicht durch den neuen Stand ersetzen.
2. Im bisherigen Anwendungsverzeichnis eine Sicherung der Datei
   data/rollout.sqlite anlegen.
3. Die Dateien der Version 0.1.30 auf den Server kopieren.
4. Im Anwendungsverzeichnis einmal ausführen:

   php tools/update-database-0.1.30.php data/rollout.sqlite

5. Nur bei der Erfolgsmeldung die Anwendung wieder aufrufen.

Das Skript akzeptiert ausschließlich Schema-Version 22 und legt zusätzlich
eine automatisch benannte Sicherungsdatei neben der Datenbank an. Vorhandene
FI-/DSV-Klassen und Rückmeldungen werden auf die neue objektbezogene Struktur
übertragen. Ohne dieses einmalige Update startet Version 0.1.30 bewusst nicht.
